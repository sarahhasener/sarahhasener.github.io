Wer diese Anwendung nutzt

Der Kalender-Assistent ist ein privates Programm für eine einzige Person: die Entwicklerin selbst. Es steht anderen nicht zur Verfügung, es gibt keine Registrierung und keine weiteren Nutzerkonten.

Welche Daten verarbeitet werden

Über die Google Calendar API greift das Programm auf das eigene Google-Konto zu und verarbeitet:

  • Kalendereinträge: Titel, Beschreibung, Datum, Uhrzeit, Wiederholungsregeln, Termin-IDs, Frei/Belegt-Status
  • die Liste der Kalender des Kontos und deren Namen

Über den privaten Telegram-Bot verarbeitet das Programm zusätzlich:

  • den Text der Nachrichten, die die Entwicklerin selbst an ihren Bot schickt, sowie die zugehörige Chat-ID

Andere Daten aus dem Google-Konto werden nicht abgerufen. Es gibt keine Kontakte-, E-Mail-, Drive- oder Standortzugriffe.

Wozu die Daten verwendet werden

Ausschließlich dazu, Termine anzuzeigen, einzutragen, zu ändern oder zu löschen und Notizen in einer lokalen Aufgabenliste zu sammeln. Es findet keine Auswertung zu anderen Zwecken statt, kein Profiling, keine Werbung, keine Analyse des Nutzungsverhaltens.

Wo die Daten liegen

Das Programm läuft lokal auf einem privaten Mac. Kalenderdaten werden im Arbeitsspeicher verarbeitet und nicht dauerhaft gespeichert. Dauerhaft auf dem Rechner liegen:

  • die Zugangsdaten für die Google Calendar API und den Telegram-Bot (Zugriffs- und Aktualisierungs-Token) in einer nur für den eigenen Benutzer lesbaren Datei
  • eine Textdatei mit den eingegangenen Notizen
  • Protokolldateien der Hintergrunddienste, die regelmäßig gekürzt werden

Es gibt keinen Server, keine Cloud-Speicherung durch dieses Programm und keine Datenbank. Die Website, auf der Sie diesen Text lesen, ist eine reine HTML-Seite ohne Formulare, ohne Cookies, ohne Tracking und ohne Analysewerkzeuge. Sie wird bei GitHub Pages gehostet; GitHub verarbeitet dabei technisch bedingt Zugriffsdaten wie die IP-Adresse. Siehe dazu die Datenschutzerklärung von GitHub.

Weitergabe an Dritte

Es werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt. Datenübertragungen finden nur gegenüber den Diensten statt, die für die Funktion nötig sind: Google (Calendar API) und Telegram (Bot API).

Speicherdauer

Notizen und Protokolle bleiben so lange auf dem Rechner, bis sie gelöscht oder überschrieben werden. Zugangs-Token werden bei einer erneuten Anmeldung ersetzt und beim Entzug des Zugriffs ungültig.

Zugriff widerrufen

Der Zugriff dieser Anwendung auf das Google-Konto kann jederzeit unter myaccount.google.com/permissions entzogen werden. Danach funktioniert der Kalenderzugriff des Programms nicht mehr.

Rechte

English summary

Kalender-Assistent is a private, single-user application. Using the Google Calendar API it accesses only the developer's own calendar data (event titles, descriptions, dates, times, recurrence rules, event IDs, busy/free status, calendar list). It also processes text messages the developer sends to her own private Telegram bot. No other Google data is accessed. Data is processed locally on a private Mac; only API tokens, a notes file and log files are stored on disk. Nothing is shared with third parties, sold, or used for advertising or profiling. Access can be revoked at any time at myaccount.google.com/permissions. Contact: sarahhasener8@gmail.com.
